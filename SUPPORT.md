# Support

## Gameplay and bugs

Use the repository issue templates for reproducible bugs and feature proposals:

<https://github.com/anjulalk/tuktukio/issues>

Include the browser, operating system, whether you used the Cloudflare Worker or Node fallback, and exact steps. Do not post credentials, admission tickets, or private room data.

## Security

Do not open a public support issue for a vulnerability. Follow [SECURITY.md](SECURITY.md).

## Live service

<https://tuktukio.anjula.dev>

If the service is unavailable, check:

- <https://tuktukio.anjula.dev/api/health>
- <https://tuktukio.anjula.dev/api/ready>
- [GitHub Actions](https://github.com/anjulalk/tuktukio/actions)

See [docs/10-production.md](docs/10-production.md) for the operator runbook.
