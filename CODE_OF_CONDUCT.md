# Code of Conduct

## Our pledge

We want TukTuk.io to be a welcoming, respectful, and constructive open-source community. Participants are expected to be kind, assume good intent, accept constructive feedback, and avoid harassment or personal attacks.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, doxxing, spam, deliberate disruption, and publishing another person's private information are not acceptable.

## Scope

This policy applies in repository issues, pull requests, discussions, Actions, community spaces, and public representation of the project.

## Reporting

Report conduct concerns privately through the repository's GitHub Security Advisory channel or the project owner's private contact. Do not include credentials or sensitive user data.

## Enforcement

Maintainers may edit or remove contributions, issue warnings, restrict participation, or ban participants when behavior violates this policy. Reports will be handled as confidentially as practical.

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
