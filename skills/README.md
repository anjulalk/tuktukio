# TukTuk.io Agent Skills

These are focused playbooks for AI agents. They are intentionally short and point back to source-of-truth files.

- [`tuktuk-gameplay/SKILL.md`](tuktuk-gameplay/SKILL.md) — gameplay, protocol, and state-boundary work.
- [`cloudflare-deploy/SKILL.md`](cloudflare-deploy/SKILL.md) — Worker, Durable Objects, domains, and CI/CD.
- [`repo-maintenance/SKILL.md`](repo-maintenance/SKILL.md) — documentation, tests, issues, and release hygiene.

Before using a skill, read the root `AGENTS.md` and the nearest subsystem `AGENTS.md`. Never put secrets in a skill, issue, commit, log, or generated report.
